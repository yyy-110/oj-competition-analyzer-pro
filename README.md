# OJ 竞赛多班级全景分析专业版 (oj-competition-analyzer-pro)

专为 `krand.site` (HUSTOJ) 打造的多班级教学竞赛全景分析系统。

## ✨ 核心特性

1. **Excel 班级名单多列解析**：
   - 支持多列排布的 Excel 文件（每列第一行为班级名，下方为学生姓名）；
   - 自动容错清洗与未分班兜底。

2. **真实用户名主键与脱敏双模一键切换**：
   - 统一提取真实用户名 `user`（如“许珺杰2028”），废弃乱填的自定义昵称 `nick`；
   - 支持一键在教师实名审计版与学生代号匿名脱敏版（如 `Student_001`）之间即时切换。

3. **全模块单页多班级即时动态联动**：
   - 顶部提供班级切换选择器（`[全年级总览]`、`[高二(1)班]`、`[高二(2)班]`...）；
   - **第一部分**：每日提交活跃度柱状图按班级实时重绘；
   - **第四部分**：代码异常审计（4.1~4.4）按班级纯净下钻过滤；
   - **第五部分**：学生做题明细按班级即时过滤与搜索；
   - **第六部分**：AC 算法流派自动过滤 0 人流派，**100% 展示当前班级学生的真实 AC 代码样例**；
   - **第七部分**：典型错误代码诊断自动过滤 0 命中模式，**100% 展示当前班级学生的真实错误代码与提交 ID**。

4. **专属【📊 班级横向对比大屏】**：
   - 上方控制栏独立激活大屏；
   - 各班综合指标矩阵表（支持表头即时排序）；
   - 25 道题目攻关率热力对比全景表。

5. **精简 7 个主 Tab 导航架构**：
   - 移除冗余分屏，下方主导航严格保持 7 个分析 Tab，体验流畅紧凑。\n
